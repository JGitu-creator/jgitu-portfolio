# Jim Gitu — Portfolio Website

Zero-build static HTML5/CSS3/vanilla JS portfolio for **Jim Gitu** (`www.jimgitu.com`).

## Structure

- `index.html` — Semantic, accessible landing page featuring Dassah's Prism and verified programme, curriculum, and partnership case studies
- `styles.css` — Responsive editorial layout with WCAG AA contrast
- `script.js` — Progressive enhancement for track filtering, mobile navigation, and one-click email copy

## Local Preview

Serve the folder with any static HTTP server:

```bash
python3 -m http.server 8080 --directory portfolio-site
```

Then open `http://localhost:8080`.
